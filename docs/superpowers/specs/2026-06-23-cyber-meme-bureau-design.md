# 赛博表情包制造局 (Cyber Meme Bureau) 设计文档

## 1. 产品概述

**产品名称：** 赛博表情包制造局
**产品类型：** 基于 Web 端的 AI 图像动态表情无缝融合网页应用
**核心价值：** 让普通用户零门槛制作"属于自己"的高质量搞笑表情包

**目标用户：** 热爱"网感"文化的年轻人、大学生群体、职场打工人

**使用场景：** 微信群斗图、朋友圈恶搞互动、节日/生日专属搞笑祝福

---

## 2. 功能范围

### 2.1 核心创作流程

| 步骤 | 功能 | 说明 |
|------|------|------|
| 1 | 上传照片 | 用户提交单人照片 |
| 2 | 选择模板 | 从内置库或用户上传中选择表情包模板 |
| 3 | AI 融合 | 调用第三方 AI API 进行面部处理 |
| 4 | 编辑成品 | 添加文字、涂鸦、裁剪 |
| 5 | 下载/分享 | 生成最终表情包 |

### 2.2 AI 融合方式

| 方式 | 说明 | 适用场景 |
|------|------|----------|
| 换脸融合 (Face Swap) | 把用户照片的脸替换到模板表情的脸上 | 动态 GIF、已有角色表情包 |
| 表情驱动 (Expression Transfer) | 检测用户表情，驱动模板角色做出相同表情 | 静态模板、熊猫头等 |

### 2.3 融合风格选项

- **幽默恶搞风** - 脸融合后有点"违和萌"，正常脸配夸张表情，制造反差笑点
- **自然混搭风** - 脸和模板融合得比较自然，配上文字产生搞笑效果
- **魔性合成风** - 脸被 AI 处理成 Q 版/卡通感，和模板浑然一体

### 2.4 编辑功能

| 功能 | 说明 |
|------|------|
| 顶部文字 | 在画面顶部添加搞笑文字（类似熊猫头模板） |
| 底部文字 | 在画面底部添加搞笑文字 |
| 对话气泡 | 给人物添加对话框/气泡 |
| 手绘涂鸦 | 自由绘制、标注 |
| 裁剪 | 调整画面构图和尺寸 |

### 2.5 模板管理

| 来源 | 说明 |
|------|------|
| 内置模板库 | 预置经典熊猫头、表情包 GIF 等 |
| 用户上传 | 支持用户自行上传模板 |

## 3. 技术方案

### 3.1 前端技术栈

- **框架：** 主流前端框架（React/Vue）
- **图像处理：** Canvas API / Fabric.js（编辑器）
- **AI 能力：** 第三方 AI API（换脸、表情识别）

### 3.2 后端技术栈

- **Web 服务：** Node.js / Python
- **AI API 集成：** 阿里云、腾讯云等第三方换脸/表情识别 API
- **文件存储：** 云存储 OSS / 本地存储

### 3.3 第三方 AI API 能力要求

- 人脸检测与特征提取
- 人脸替换/融合
- 表情识别

## 4. 页面结构

```
首页
├── 照片上传区
├── 模板选择区（内置 + 用户上传 Tab）
├── 融合参数设置
│   ├── 融合方式选择（换脸/表情驱动）
│   └── 风格选择（幽默恶搞/自然混搭/魔性合成）
├── 预览区
└── 编辑工具区
    ├── 文字工具（顶部/底部/气泡）
    ├── 涂鸦工具
    └── 裁剪工具
```

---

## 5. 数据流

```
用户上传照片 → 前端压缩/预览 → 发送给后端
                                      ↓
                               调用 AI API 进行融合
                                      ↓
                               返回融合结果到前端
                                      ↓
前端编辑（文字/涂鸦/裁剪） → 生成最终图片 → 下载/分享
```

---

## 6. 约束与限制

- 仅支持单人照片
- 模板需为表情包类型
- 用户上传内容需审核（防滥用）
- AI API 调用有频率/成本限制
